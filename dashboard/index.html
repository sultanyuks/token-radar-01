How the implied value is priced

The snapshot prices its own future launches. Of its 758 protocols, the ones whose token already trades carry both a TVL and a market cap; the median market-cap/TVL ratio of those pairs is the market's own answer to “what is a dollar of TVL worth once it has a token?”. Each pre-token protocol is priced at its category's median ratio — shrunk toward the global median so a thin category cannot shout — adjusted for its 7-day TVL momentum and for how long it has run with no token recorded:

implied value = TVL × category peer multiple × growth factor × seasoning factor

  • Growth factor = 1 + clamp(7-day change, −50%…+100%) × 0.6. Unreported change counts as 0.
  • Seasoning factor = 0.75 + 0.5 × min(age, 1,460 days) / 1,460. Longer tokenless, richer the accrued unpriced activity; an unrecorded listing date sits at the neutral 730 days.
  • No name is special-cased. The same function scores every row, and every multiple is recomputed from the snapshot at run time — re-run on a future snapshot, the same program finds future launches early.
  • Pre-token means “records no token” in DefiLlama's record (no market cap, no CoinGecko id, no symbol) — a claim about the record, never proof a token does not exist. Trading protocols sit in the Live view at the market's own values, never mixed into this ranking.
